# コーヒーレンス

## 「なんとなく美味しい」を、次に試すことに変える

コーヒーの淹れ方を練習するためのアプリ（ネットにつながっていなくても動きます）

<!-- 0:15 — 名乗って一文で言い切る。「コーヒーの練習ノートを、次の一手が決まるノートにするアプリです」 -->

---

## 誰の、どんな困りごとか

コーヒーを淹れる技術を競う大会があります。出場する選手は豆も時間も限られています。

- 大会で使える豆は **数百 g**。練習で淹れられるのは全部で数十杯まで
- 本番でお客さん（審査員）に出せるのは **2回**だけ
- なのに手元に残るのは「たぶんこっちが美味しかった」という **記憶**だけ

## このアプリがやること

| 知りたいこと | 出るもの |
| --- | --- |
| どっちの淹れ方が良かったのか | 差がはっきりある / 分からない、の判定 |
| 次はどこを変えればいいか | 次に試す1杯の提案 |
| 本番で絶対に外せない条件は何か | 練習の記録から出す注意点 |
| 2回のうちどう攻めるか | 安全に行く / 勝ちを狙う の目安 |

## 工夫①：正解を隠して、自分のブレも測る

- 練習の中に **同じコーヒーをこっそり2杯**まぜる
- その2杯の点数のズレが、その日の **自分のブレの大きさ**
- ブレより小さい差は **「分からない」と表示**して、思い込みで決めさせない
- 採点中はどの淹れ方か画面に出さない。答え合わせの後は点数を直せない

<!-- 0:55 — 新しいのは「味の差を測る前に、自分の目盛りを測る」ところ。後から都合よく直せない作りも。 -->

---

## 工夫②：点数をつけずに「どっちが好きか」で選ぶ

- 総合の良さは点数にしづらいので、**2杯を並べてどちらが好きかだけ**を答える
- その積み重ねから、全体の順位と「どのくらい自信があるか」を出す
- 「A>B、B>C なのに C>A」のような矛盾も見つけて、自信度に反映
- 練習の記録から、本番2回の **狙い方の目安**まで出す

## Supabase：練習は手元、共有はクラウド

- **ログイン**は共有機能を使うときだけ。練習だけならログイン不要
- 投稿とプロフィールはクラウドに保存。**他人の投稿は書き換えられない**設定
- 他の端末の投稿が **その場で流れてくる**（リアルタイム）
- 不適切な投稿は、アプリ側だけでなく **データベース側でも保存を拒否**
- クラウドが無い状態でも動くので、**オフラインの体験は壊れない**

## 届く価値

- 同じ豆の量から **わかることが増える**（「分からない」を認められるから）
- 練習ノートが感想から **人に説明できる記録**になる
- まず競技者。その先はカフェの味の管理や、焙煎の味見にもそのまま使える
